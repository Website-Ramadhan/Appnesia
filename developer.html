AppNesia Untuk Developer

Kirim aplikasimu ke AppNesia

AppNesia adalah katalog aplikasi di Indonesia. Developer bisa mengirim aplikasinya agar masuk ke daftar, termasuk aplikasi yang tidak ada di Play Store.

Cara kerjanya
  • Kamu mengisi formulir di bawah.
  • Formulir membuat kiriman di GitHub (perlu akun GitHub, gratis). Kiriman itu bersifat publik, jadi jangan menulis data pribadi.
  • Sistem memeriksa isiannya secara otomatis. Kalau lolos, aplikasimu langsung tampil di katalog dengan label "Belum diverifikasi".
  • AppNesia tidak menyimpan file APK. Tombol di katalog mengarah ke halaman resmi aplikasimu.

Aturan

  • Kamu pemilik aplikasi, atau punya izin tertulis dari pemiliknya.
  • Bukan aplikasi modifikasi, bajakan, atau yang meniru merek dan nama aplikasi lain.
  • Bebas malware, iklan menipu, dan konten yang melanggar hukum.
  • Tautan harus ke halaman resmimu: Play Store, GitHub Releases, atau situsmu sendiri. Harus diawali https://.
  • Pengguna bisa melaporkan aplikasi. Admin berhak menghapus aplikasi kapan saja. Satu akun GitHub maksimal 3 aplikasi.
  • Kiriman ditolak otomatis jika nama atau tautannya sudah ada, atau tautannya memakai pemendek tautan (bit.ly dan sejenisnya).

Buka di GitHub

AppNesia tidak berafiliasi dengan Google, Play Store, atau developer lain yang namanya muncul di katalog. Nama dan merek aplikasi milik pemiliknya masing-masing.
